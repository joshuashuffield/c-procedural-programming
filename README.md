# Procedural C Programming & Pointer Architecture
A collection of procedural C programs developed for COSC 1310 (Procedural Programming) at Tarleton
State University. Focuses on data structures, memory layout, and pointer manipulation.
## Core Concepts Implemented
- **Pointers & Pass-by-Reference**: Modular functions modifying state via pointer dereferencing (`int
*passCount`, `*failCount`).
- **Custom Structures**: Multi-field record management using custom `struct Student` arrays.
- **Multi-Dimensional Arrays**: 2D matrix traversal, boundary verification, and nested algorithmic
processing.
- **Memory Scope & Lifetime**: Stack allocation vs static/global variable lifecycle management.
## Technologies Used
- **Language**: C (C99 / C11)
- **Compiler**: GCC / GDB
- **Development Environment**: Eclipse (Windows)
